# Talisman — Editorial Atlas

A small, hand-curated atlas of European cities, as an installable web app (PWA).

- `data/cities.json` — the city index; `data/<city>.json` — places for each city
- Cities: Paris (placeholder set, awaiting the Talisman Paris 50), London, Rome, Lisbon, Copenhagen
- Places researched with Condé Nast Traveller, Wallpaper*, Monocle, Kinfolk, AFAR, Spotted by Locals and others; all notes are original Talisman copy.
- Map: MapLibre GL with OpenFreeMap vector tiles (© OpenMapTiles, © OpenStreetMap contributors), recoloured to the Talisman palette.

Open on a phone and "Add to Home Screen".
